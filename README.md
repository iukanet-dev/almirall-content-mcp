# Almirall Official Content MCP

Official, read-only Model Context Protocol (MCP) server for searching public indexed content from Almirall websites.

## Connect

- MCP endpoint: https://mcp.almirall.com/mcp
- Agentic Resource Discovery manifest: https://mcp.almirall.com/.well-known/ard.json

The server lets AI assistants search public Almirall content and find relevant pages, sources, product mentions, comparisons, and embedded assets.

## Example requests

- What ingredients or plant extracts does Almax mention?
- Compare Physiorelax Polar and Ultra Heat using Almirall's published content.
- Find the official page describing how to use an Almirall product.
- Which public Almirall pages mention warnings for a product?
- Find images or other assets embedded in official Almirall product pages.

## Scope

This MCP searches public indexed website content. It is read-only and does not provide medical advice or access to private clinical or customer data.
